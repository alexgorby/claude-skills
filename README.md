# Скіли Claude для українського письма

**Українська** · [English](README.en.md)

Два скіли для Claude, які допомагають писати українською так, щоб текст не
звучав як переклад чи машинний: без кальок, канцеляриту й ШІ-кліше. Кожен скіл —
окремий плагін, тож можна поставити один або обидва.

| Плагін | Для чого |
|---|---|
| `ukrainian-tech-docs` | Технічна документація: контракт роботи перед письмом, дисципліна джерел і маркерів невизначеності, жива мова, жанрові правила (HLD, LLD, ADR, how-to і runbook, concept, reference, troubleshooting, постмортем, схема, план), питання до суміжних команд, вивантаження в .docx, .xlsx, .pdf чи лист |
| `ukrainian-fiction` | Художня проза: мова без кальок і ШІ-кліше, правопис і милозвучність, речення й абзац, діалог, будова сцени й глави, аудит готового тексту. Правила конкретної книги (герої, словник, лор, тон) скіл не тримає — їх дає профіль книги |

## Встановлення

### Claude Code

```
/plugin marketplace add alexgorby/claude-skills
/plugin install ukrainian-tech-docs@alexgorby-skills
/plugin install ukrainian-fiction@alexgorby-skills
```

Скіл вмикається сам, коли ви просите написати, перевірити чи почистити
український текст відповідного жанру.

### Claude Desktop і claude.ai

Додайте маркетплейс як плагін або завантажте скіл архівом: налаштування →
Skills → додати власний скіл. Архів збирає `pwsh ./build.ps1` у теку `dist/`.

### Інші агенти

Скіл — звичайна тека з `SKILL.md`. Її можна скопіювати в теку скілів будь-якого
агента, що підтримує цей формат.

## Будова репозиторію

```
.claude-plugin/marketplace.json     перелік плагінів
plugins/
  ukrainian-tech-docs/
    .claude-plugin/plugin.json
    skills/ukrainian-tech-docs/     SKILL.md, references/, templates/
  ukrainian-fiction/
    .claude-plugin/plugin.json
    skills/ukrainian-fiction/       SKILL.md, references/, templates/
build.ps1                           збирає zip для ручного завантаження
```

## Джерела

Правила написано наново українською. Ідеї частково взято з досліджень і чужих
скілів; англомовні правила перенесено лише там, де вони працюють для української.
Повний перелік з посиланнями — у розділі «Джерела пакета» в `SKILL.md` кожного
скіла.
