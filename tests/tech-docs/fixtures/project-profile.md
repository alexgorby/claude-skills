# Профіль синтетичного проєкту
Усі матеріали тестові, не про реальні продукти.
Сходи джерел: єдине замкнене джерело умовного продукту — sources.md; зовнішніх немає.
Реєстр кодів: codes.md.
Термінологія: glossary.md.
Відкриті питання: у чаті; адресат технічних проб — власник стенда.
Реєстр зовнішніх документів, профілі вивантаження, палітри, проєктні жанри: немає.
Конвенція метаданих: немає; метаданих не додаємо.
Свідомі відступи: факти умовного продукту перевіряються за локальним sources.md, URL не вигадуються. Результат усіх завдань у чаті, без запису робочого документа, якщо явно не сказано інше.
