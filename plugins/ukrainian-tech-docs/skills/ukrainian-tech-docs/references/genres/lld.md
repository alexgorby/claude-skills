# LLD — Low-Level Design

LLD тримає значення: адреси, VLAN, моделі, версії, параметри, шляхи, розклади,
порядок кроків. Рішень він не ухвалює і не переобґрунтовує — він показує, чим
рішення HLD стає в конфігурації.

Поруч читати: `evidence.md`, `language.md`, `hld.md` розд. 3 (межа глибини).

## 1. Вхід

Жанр названо в контракті роботи. Рядок «Звідки наповнення» тут головний: у LLD
кожне значення має походження, і воно одне з трьох.

| Походження | Що стоїть поруч зі значенням |
|---|---|
| Наслідок рішення | посилання на рішення HLD або ADR, з якого значення випливає |
| Вимога чи дефолт вендора | URL сторінки в місці значення (`evidence.md`, розд. 1) |
| Знято із середовища | чим знято — команда, звіт, зріз — і коли |

Значення без походження є рішенням, ухваленим у LLD мовчки. Його місце —
у HLD або ADR, і воно туди повертається.

## 2. Межа з HLD

| Група | У LLD |
|---|---|
| Контекст системи | не повторюється — посилання на HLD |
| Компоненти | моделі, версії, параметри |
| Дані | томи, шляхи, розклади, розміри |
| Розгортання | адреси, VLAN, порядок кроків, значення |
| Рішення й обмеження | наслідок рішення в конфігурації |

Обґрунтування рішення в LLD не переписується: один рядок «чому так» із посиланням
на HLD. Два тексти одного обґрунтування розходяться після першої правки.

Порядок кроків у LLD — це послідовність із залежностями, не процедура для
виконавця. Процедура з перевіркою і відкатом — окремий документ жанру `howto.md`;
LLD дає йому значення.

## 3. Вимоги до тексту

- Значення стоять таблицями з однаковим набором колонок по всьому документу;
  проза лишається там, де пояснюється залежність між значеннями.
- Значення, що повторюється в кількох місцях, має одне джерело істини в документі;
  решта місць на нього посилаються.
- Реальні ідентифікатори продуктиву, секрети й ключі в документ не йдуть —
  називається місце, звідки вони беруться.
- Спостереження зі стенда, яке в HLD не могло бути підставою, тут доречне:
  з датою, способом зняття і назвою середовища.
- Двозначний термін уточнюється в кожному рядку (`language.md`, 2.5): у LLD
  «вузол» без уточнення майже завжди двозначний.

## Чек-лист LLD

- [ ] Кожне значення має одне з трьох походжень
- [ ] Жодного рішення, якого немає в HLD або ADR
- [ ] Обґрунтування не переписане з HLD, а адресоване на нього
- [ ] Кожне повторюване значення має одне джерело істини
- [ ] Немає секретів і реальних ідентифікаторів продуктиву
- [ ] Чек-листи `evidence.md` і `language.md`
