# Профіль проєкту для пакета письма документів

> Шаблон. Заповнений файл живе в проєкті; інструкції проєкту або його кореневий
> файл для агента вказують на нього одним рядком. Метадані файла — за конвенцією
> проєкту, не за цим шаблоном.
>
> Профіль нічого не визначає сам: у кожному слоті стоїть **адреса**, де вміст
> лежить у проєкті. Таблиця значень сюди копіюється тільки тоді, коли іншого
> місця в неї немає. Порожній слот — законний стан: пишеться «немає», а не вигадка.

## 1. Сходи джерел

| 2 — офіційні блоги й виступи інженерів вендора | <перелік> |
| 3 — вендори обладнання чи суміжних продуктів | <три-чотири імені> |
| 4 — RFC і стандарти галузі | <органи стандартизації, що мають предмет у проєкті, або «за пошуком»> |
| 5 — академічні джерела | <перелік або «за пошуком»> |
| 6 — профільні форуми й блоги практиків | <перелік або «за пошуком»> |
