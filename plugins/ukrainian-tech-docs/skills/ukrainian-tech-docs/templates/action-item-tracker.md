## Правила ведення

Дія, перенесена двічі, виноситься на обговорення з керівником напрямку: або
з'являється ресурс, або її знімають із формулюванням, який ризик прийнято свідомо.
Мовчазне перенесення втретє означає, що трекер більше не відображає реальність.

Перед новим розбором дивляться, чи є в трекері відкриті дії з тим самим класом
відмови. Якщо є, це перший факт у новому документі.

Раз на квартал рахують два числа: частку закритих дій у строк і кількість
інцидентів, де повторився вже описаний клас відмови. Друге число, що зростає при
першому близькому до нуля, показує, що розбори пишуть, але не виконують.
