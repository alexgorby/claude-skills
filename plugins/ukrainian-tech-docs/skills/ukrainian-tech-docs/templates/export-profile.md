## 1. Що це за файл і чого він не описує

Предмет файла одним абзацом. Окремо — чого він **не** описує й де це живе.
Який документ є джерелом істини, якщо цей файл — чернетка до нього.

**Спадковість форми.** Якщо оформлення успадковане від іншого профілю: від якого,
що взято без змін, що додано, коли звірено з оригіналом. Успадкування, не звірене
з оригіналом, з часом перестає бути правдою. Профіль без спадковості цей абзац знімає.

**Групи рядків.** Якщо рядки частини згруповані — смугами розділів, рівнями
структури, гніздами «батьківський рядок і дочірні» — описати рівні, що стоїть
на кожному, як нумеруються рядки й чи згорнуті групи за замовчуванням. Частина
з пласким переліком рядків цей абзац знімає.

## 9. Збірка

Чим збирається файл. Де лежать дані, де оформлення. Порядок полів запису.

**Налаштування каналу.** Заміни, яких вимагає канал чи читач цього файла, а не
мова: наприклад, довге тире `—` на дефіс `-`. Заміна робиться на збірці, джерело
не змінюється. Файл без таких замін цей абзац знімає.
