# Планування

Правила плану й чек-листа лежать у `../../shared/genres/plan.md` від теки цього
скіла. Загальні правила тексту — `../../shared/genres/general.md`, джерела й
маркери — `../../shared/evidence.md`.

## 1. Порядок

1. Перевірити вмикання за `genres/plan.md` (вступ). Не ввімкнено — скіл не
   працює, а робота йде в `write` чи інший скіл.
2. Профіль проєкту (`write/SKILL.md`, розд. 2), якщо робота в проєкті.
3. Вирішити, що потрібно: лише чек-лист для малої задачі на одну сесію чи план
   і чек-лист (`genres/plan.md`, розд. 1); чи дорого читання входу й чи потрібні
   п'ять рядків (розд. 2–3).
4. Скласти план за розд. 4, чек-лист — за розд. 5.
5. Самоперевірка: чек-лист `genres/plan.md`, фінальний прохід за
   `language.md`.
6. Закривальний рядок (`write/SKILL.md`, розд. 3):
   `Стадії: планування (plan/SKILL, genres/plan, genres/general) · самоперевірка (чек-лист плану, фінальний прохід)`.
7. Рецензія скілом `review`, режим «план», — лише на прохання власника, до
   погодження плану.
8. Під час виконання — зміни плану записом у журнал рішень плану, зміни
   чек-листа й власні рішення — за розд. 5, зупинки — за розд. 6.

Відміна власника на будь-якому кроці (`genres/plan.md`, розд. 7) зупиняє
скіл: запис відміни з причиною, далі робота без плану.
