# Планування

Правила жанру плану лежать у `../../shared/genres/plan.md` від теки цього
скіла. Загальні правила тексту — `../../shared/genres/general.md`, джерела й
маркери — `../../shared/evidence.md`.

## 1. Порядок

1. Перевірити, що власник прямо попросив план. Ні — скіл не працює, а робота
   йде в `write` чи інший скіл.
2. Профіль проєкту (`write/SKILL.md`, розд. 2), якщо робота в проєкті.
3. Скласти план за `genres/plan.md`.
4. Самоперевірка: чек-лист `genres/plan.md`, фінальний прохід за
   `language.md`.
5. Закривальний рядок (`write/SKILL.md`, розд. 3):
   `Стадії: планування (plan, genres/plan, general) · самоперевірка (чек-лист plan, фінальний прохід)`.
6. Коли власник каже, що план готовий, — рецензія скілом `review`, режим
   «план».
