# Reference — схеми даних, метрики, коди

Тільки таблиці й код. Прози між ними немає.

Однотипні таблиці мають однаковий набір колонок: усі схеми даних мають одні
колонки, усі коди помилок — інші. Різні сутності потребують різних колонок.
Шаблон проєкту, якщо він є, старший за приклад нижче. Для схеми даних:

```markdown
| Поле | Тип | Обов'язкове | Опис | Приклад |
```

Одна таблиця — одна сутність. Якщо таблицю треба пояснювати абзацом — пояснення
переїжджає в Concept, а тут лишається посилання.

Однакова структура рядків тут вимога, а не ознака машинного тексту: варіативність
(`language.md`, 1.5) до таблиць не застосовується.

Значення з документації вендора несе адресу в рядку (`evidence.md`, розд. 1);
значення, зняте із середовища, — чим і коли знято.
