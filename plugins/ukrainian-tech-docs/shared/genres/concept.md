# Concept — як працює компонент

Поруч читати: `evidence.md`, `language.md`. Дійова особа = компонент, теперішній час.

```markdown
# <Іменник> — <що це одним рядком>

## Навіщо
Яку проблему розв'язує. 2–3 речення.

## Як працює
Схема плюс опис потоку даних. Дійова особа = компонент.

## Ключові поняття
Термін — визначення. Плоским списком, без вкладеності.

## Обмеження
Що не вміє, за яких умов ламається.

## Пов'язане
```

`## Навіщо` тут — заголовок цілого розділу, не ярлик перед абзацом
(`language.md`, 1.12), і він лишається.

Кроки виконання в Concept не йдуть: процедура виноситься в How-to, сюди стає
посилання. Механізм із кількома одночасними учасниками або потоком даних між
зонами — предмет для схеми (`schema.md`, розд. 1).

## Чек-лист Concept

- [ ] Заголовок — сутність і що це одним рядком
- [ ] «Як працює» описує механізм, а не перелічує властивості
- [ ] Є «Обмеження» з умовами, за яких компонент ламається
- [ ] Немає кроків процедури
- [ ] Чек-листи `evidence.md` і `language.md`
