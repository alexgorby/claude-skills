# Аудит готового тексту

Читати на стадіях Аудит і Самоперевірка. Нумерація А1–А5 стабільна.

---

## А1. Режим аудиту

Аудит вмикається запитом автора: «почисти», «перевір», «чи звучить це як
ШІ», «що не так із главою». Аудит **повертає знахідки, а не переписаний
текст**. Правка — окреме рішення автора після таблиці, і йде вона за
правилами проєкту з інструкцій: що можна правити без дозволу, а що ні.

Кожна знахідка називає номер пункту пакета, який порушено (`Л3`, `Р6`,
`С1`…). Без номера знахідку не звести в таблицю й не перевірити, чи
її знято.

**Чий текст.** Текст автора й текст, написаний моделлю, перевіряються
однаково, але пастки різні. У тексті моделі шукати сліди породження
(Л1, Л3, Л5, Л7–Л9, Р1–Р6, С1–С14). У тексті автора, який уже правила модель, —
ще й слід редагування: модель-редактор доливає порожнє навколо змісту
(Sepia, style-pass §4). Від нього — тести А4.

## А2. Порядок рівнів

Від великого до малого: будова → дискурс → діалог → речення → мова →
кальки → правопис. Не шліфувати речення в сцені, яку, можливо,
переставлять чи викинуть
([creative-writing-skills, editor.md](https://github.com/haowjy/creative-writing-skills/blob/0d5bf7f/cw/agents/editor.md)).

| Рівень | Файл і пункти |
|---|---|
| Будова глави й сцени | `scene-chapter.md`, С1–С7, С11–С14 |
| Дискурс: відкриття, середина, питання абзаців | `scene-chapter.md`, С8–С10 |
| Діалог | `dialogue.md`, Д1–Д6 |
| Речення й абзац | `sentence.md`, Р1–Р8 |
| Мова | `language.md`, Л1–Л10 |
| Кальки | `calques.md`, окремим проходом за К3 |
| Правопис і милозвучність | `orthography.md`, О1–О7 |

Аудит, замовлений на один рівень («перевір тільки діалоги»), іде лише
цим рівнем.

## А3. Таблиця знахідок

`№ · пункт пакета · де (глава й цитата до десяти слів) · що не так ·
варіант · впевненість (висока / сумнів) · вердикт (порожній, заповнює автор)`

- **Порядок — за ціною для читача, а не за сторінками.** Спершу те, що
  ламає сцену, наприкінці — дрібниці.
- **Питати, не наказувати.** Де правка змінила б зміст, голос чи канон:
  «Ви мали на увазі X? Читач може прочитати Y», а не «змініть X на Y».
- **Голос автора — не помилка.** Перш ніж назвати звичку вадою, перевірити,
  чи це не свідомий прийом: слот «Канон голосу» й «Словник книги» профілю,
  власні глави автора.
- **Скупчення, не випадок.** Одна знахідка за Л9, Р3 чи Р1 — рядок
  із впевненістю `сумнів`; той самий шаблон по всій главі — `висока`.

## А4. Тести правки

Застосовуються до кожної правки — і своєї, і запропонованої автору
(Sepia, style-pass §4).

- **Тест вилучення.** Кожне додане слово чи зворот викреслити. Речення
  й далі тримається й каже те саме — додане було зайвим, прибрати.
- **Тест повернення.** На місце кожної заміни повернути старе. Старе було
  справним і казало те саме коротше — лишити старе.
- **Ремонт проходить обидва тести.** Потрібний прийменник, підмет для
  розбитого речення, дієслово замість віддієслівного іменника (Л1),
  перестановка, що робить речення граматичним.
- **Уривок не довшає.** Повернення живого регістру (Л10) допустиме, лише
  якщо та сама правка десь у цьому уривку прибрала порожнє.

**Правка точкова.** Автор цитує фразу — правиться саме вона. Сусідній
текст не чіпається, навіть якщо в ньому видно іншу знахідку: її — окремим
рядком таблиці.

## А5. Фінальний прохід

Перед тим як віддати текст, поставити собі питання: **«Що тут досі звучить
як ШІ?»** — і пройти чек-лист нижче. Це окремий крок по готовому тексту,
а не «я писав, тримаючи правила в голові».

Коли правка стосується цілого класу конструкцій (кальки, слова-фільтри,
ремарки), прогнати її пошуком по всій главі, а не на око: те саме слово
зазвичай стоїть у трьох місцях, і два лишаються невиправленими.

### Чек-лист

**Будова**
- [ ] Оповідач не проговорює тему й урок; символи не пояснено — С1
- [ ] Перевірено тест луни для головних поворотів — С2
- [ ] Кінцівка не стоїть на трьох ногах «вибір + прийняття + розуміння» — С3
- [ ] Контекст не вивалено на початку; терміни введено вжитком — С4
- [ ] Важливі рішення героя мають наслідки поза цією главою — С5
- [ ] Персонажа виведено в дії чи розмові; мережа не густа й не вся тепла — С6
- [ ] Справжні речі названо там, де канон це дозволяє — С7
- [ ] Відкриття — посеред дії, а не «час, місце, погода, опис» — С8
- [ ] У середині є подія, якої відкриття не передбачає — С9
- [ ] Перші речення абзаців не складаються в чистий конспект — С10
- [ ] Імена не з тих, на яких сходяться моделі — С11
- [ ] Не більше одного свідомо рідкісного ходу — С12
- [ ] Якщо відомо, яка модель писала, її почерк перевірено за рядком — С13
- [ ] Сцена може закінчитися інакше; немає хибних виборів, механізму замість сцени, промов — С14

**Діалог**
- [ ] Репліки роблять по дві справи; є підтекст — Д1, Д2
- [ ] Голоси впізнавані без ремарок — Д3
- [ ] Ремарки прості, без ротації дієслів мовлення — Д4
- [ ] Реакції не стоять біля майже кожної репліки — Д5
- [ ] Суперечка — про конкретне, не про ідеї — Д6

**Речення й абзац**
- [ ] Немає низок із трьох і більше речень однакової довжини — Р1
- [ ] Абзаци не однакові; абзац не закінчується щоразу «красивою» фразою — Р2
- [ ] Немає шаблонів «не X, а Y», переліку заперечень, драматичного дроблення, поглядів без причини, округлених монологів, скупчень прислівників — Р3
- [ ] Кліше замінено свіжим, а не блідішим — Р4
- [ ] Деталі конкретні й пройшли крізь увагу персонажа — Р5
- [ ] Почуття переважно поведінкою й назвою; тілесний спосіб — лише на піках — Р6
- [ ] Дистанція оповідача рухається, а не стоїть посередині — Р7

**Мова**
- [ ] Дієслова замість віддієслівних іменників — Л1
- [ ] Немає складеного пасиву; діяч не захований без причини — Л2
- [ ] Немає порожніх зворотів-хвостів — Л3
- [ ] «Є» або дієслово замість «слугує», «виступає» — Л4
- [ ] Немає примусових трійок і хибних діапазонів — Л5
- [ ] Немає родових ланцюгів і омонімів після додатка — Л6
- [ ] Немає обгорток-абстракцій і парних абстракцій — Л7
- [ ] Слова-фільтри прибрано, де сприйняття не є подією — Л8
- [ ] Немає скупчень пишномовності — Л9
- [ ] Правка не зробила уривок довшим — Л10, А4

**Правопис**
- [ ] У/в, і/й, з/із/зі за милозвучністю; свідомі відступи автора не правлено — О1–О4
- [ ] Апостроф і м'який знак — О5, О6
- [ ] Репліки, слова автора, тире на місці зв'язки — О7

**Кальки** — окремим проходом за `calques.md`, К3, якщо автор його замовив.
