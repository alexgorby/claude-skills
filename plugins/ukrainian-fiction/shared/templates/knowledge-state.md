# Стан знань — <герой>, <момент>

Усе з попереднього стану лишається в силі, крім рядків розділу «Перестало
діяти»; тут — що додалося і що змінилося.

## Знає

| Факт | Звідки |
|---|---|
| | |

## Не знає

Що герой ще не знає, хоча читач чи інші герої вже знають, — і де видно, що
не знає, або коли дізнається.

| Що | Звідки |
|---|---|
| | |

## Свідомо

Що герой знає, а читач ще не бачив, і це задум автора: інтрига, таємниця,
розкриття пізніше. Звірка безперервності такого рядка не позначає
розбіжністю.

| Що знає | Задум | Коли розкриється |
|---|---|---|
| | | |

## Перестало діяти

Що з попереднього стану більше не діє на цей момент: герой дізнався те, чого
не знав, забув, переконався в хибності. Старий рядок у попередньому стані
лишається як історія свого моменту.

| Що перестало діяти | Чим замінено | Звідки перехід |
|---|---|---|
| | | |
