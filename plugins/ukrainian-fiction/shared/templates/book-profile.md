# Профіль книги — шаблон

Профіль заповнюється один раз на книгу й лежить у самому проєкті книги, не
в пакеті. Він не переказує правила книги, а лише каже, **де** вони лежать.
Пакет `ukrainian-fiction` читає профіль на вході (`profile.md`).

Кожен слот — шлях до файла або файлів і, за потреби, одне речення про те,
що там шукати. Слот, якого в книзі немає, лишається з позначкою «немає»,
а не вигадується.

## Слоти

| Слот | Де лежить | Що там шукати |
|---|---|---|
| Інструкції проєкту | | Правила роботи з автором: що писати без погодження, що редагувати, куди записувати рішення |
| Канон голосу | | Тон, межі голосу, режими оповіді, правила, які книга ставить понад пакет |
| Еталонні уривки | | Один-два абзаци, затверджені автором; читаються останніми перед письмом нової сцени чи глави. Що в них шукати — `profile.md`, «Що шукати в уривку» |
| Словник книги | | Які слова вживаються, яких уникають; свідомі відступи від норми й де саме вони дозволені; яку мовну норму тримає книга (наприклад, галицьку); форми фемінітивів; персонажі, що говорять без кличного відмінка |
| Канон фактів | | Персонажі, світ, механіки — для звірки змісту |
| Глави й чернетки | | Де лежить текст, як позначено стан глав; окремо — де лежать чистові глави: чернетку скіл править без питання, чистовик — лише на запит |
| Робочі нотатки | | Куди йдуть доробки, заділи, відкриті питання |
| Що читач знає | | Файл із переказом кожної глави очима читача: що сталося і що читач знає, без задуму автора й канону. Поповнюється після читацького тесту з погодження автора |
| Жанрові очікування | | Що жанр книги обіцяє читачеві, таблицею `очікування · що дає задоволення · що псує враження`; форма — розділ «Жанрові очікування» нижче. Заповнює автор. Не ведеться — «немає» |
| Стан знань персонажів | | Що герой знає і чого не знає на момент сцени, з джерелом; форма своя або `templates/knowledge-state.md` пакета. Не ведеться — «не ведеться» |
| Стан і час | | Документи стану й часу, рядком на документ: файл · що в ньому (графік по годинах, події по днях, поточний стан героя, стан на вході глави). Які саме — залежить від жанру й книги. Не ведуться — «не ведуться» |
| Каталоги | | Каталоги світу, рядком: файл · що в ньому · робочий канон чи витяг; протокол поповнення; де лежать джерела каталогів. Не ведуться — «не ведуться» |
| Вхідні | | Де лежать нерозібрані короткі нотатки автора. Пакет їх поки не розбирає |
| Персонажі | | Тека карток героїв за шаблоном `templates/character-card.md` пакета. Картки в книзі не ведуться — так і написати: «не ведуться» |
| Стороння модель | | Не шлях, а значення: «можна» чи «не можна» віддавати текст книги моделі іншого постачальника (другий читач у `reader`). Рядок порожній — скіл питає автора |
| Відкриті рішення автора | | Що автор ще не вирішив і на що пакет не ставить своїх правил |
| Ідеї сцен | | Не шлях, а значення: «без запуску» (пакет сам ідей сцен не пропонує) або «ідеї плюс діалог» (типово: ідеї на вибір, далі розвиток у діалозі з автором). Режиму «повністю на ШІ» тут немає: він вмикається лише запитом автора в розмові й підтвердженням (`ideas/SKILL.md`, розд. 4) |
| Самостійність правки | | Не шлях, а значення: «класи 1–2 без питання» (типово) або «питати про все». Що таке класи — `findings.md`, А7 |

### Звідки беруться еталонні уривки

Еталоном стає лише те, що вибрав автор. Помічник уривка не призначає.

| Джерело | Коли підходить | Хто формує |
|---|---|---|
| Абзац із власних глав автора | У книзі є глава, голосом якої автор задоволений | Автор вказує абзац |
| Абзац іншого автора з близьким голосом | Своїх глав ще немає або вони не тримають голосу | Автор вибирає книгу й абзац. Перед тим звірити, що уривок справді є в названому творі: модель, яку просять «процитувати автора», здатна видати власну імітацію під чужим іменем. Уривок лежить лише в профілі книги |
| Пробні уривки | Немає ні свого, ні чужого зразка | Помічник пише 3–5 варіантів однієї події в різній манері; кожен перед показом проходить `final-pass.md`, А5, інакше ознаки ШІ стануть еталоном і повторюватимуться в кожній главі. Автор вибирає або каже, що змінити, і пишеться наступне коло |
| Абзац із щойно затвердженої глави | Пізніше, на заміну першому еталону | Автор вибирає абзац: власний текст книги кращий за пробний |

### Жанрові очікування

Таблицю заповнює автор — у профілі чи в окремому файлі, на який вказує слот.
Рядок — одна обіцянка жанру: чого читач чекає, що його тішить, що псує
враження. Нижче — загальний вигаданий приклад для детективу, а не зразок для
вашої книги: обіцянки свого жанру автор формулює сам.

| Очікування | Що дає задоволення | Що псує враження |
|---|---|---|
| Чесна загадка | Розгадка спирається на підказки, які читач бачив раніше | Розгадка з факту, якого читачеві не показали |
| Слідство рухається | Кожен допит чи пошук дає нову відомість або закриває версію | Кілька сцен поспіль за однією схемою без нової відомості |
