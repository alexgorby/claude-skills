# Супровід

Внутрішній порядок роботи з репозиторієм. Для користувачів — [README.md](README.md).

## Порядок зміни

1. Правка в теці скіла (`plugins/<скіл>/skills/<скіл>/`) — лише після погодження автора.
2. Коміт; повідомлення каже, що змінено й навіщо. Перед комітом —
   `pwsh ./check.ps1 -Path <змінені файли>`: відносні посилання, незаповнені
   заготовки, чергування у/в, і/й, з/із/зі (`language.md`, 1.14), службові
   ярлики з двокрапкою (1.12), однаковий зачин у паралельних розділах (1.5);
   з `-Online` — ще й відповіді зовнішніх URL. Правка ознаки, спільної для
   обох пакетів, — ще й `pwsh ./check.ps1 -Check Shared`: реєстр
   [docs/shared-signs.md](docs/shared-signs.md) каже, де ознака живе в кожному
   пакеті, а скрипт перевіряє, що пункти на місці й форма не розійшлась.
   Зміна форми в одному пакеті тягне правку в другому тим самим комітом. Скрипт лише знаходить, і кожна
   знахідка — кандидат на рішення, а не помилка: ярлик, якого вимагає формат,
   і `і` при зіставленні понять лишаються. HTTP 403 з позначкою Cloudflare
   означає, що сторінку треба відкрити в браузері, а не що посилання бите.
3. `claude plugin validate .` — без помилок. Попередження про `version` очікуване:
   поле свідомо не задано, тож встановлені копії оновлюються за комітами.
4. Push — на слово автора. Перед push — пошук у скілах імен, назв компаній,
   колег, внутрішніх адрес і фактів із проєктів: репозиторій публічний.
5. Автор отримує скіли плагінами з маркетплейсу, доданого з контексту чату:
   тоді плагін зберігається в обліковому записі й видно в чаті, Cowork і Claude
   Code (`<скіл>@synced`). Маркетплейс, доданий з вкладки Code чи через
   `claude plugin`, лягає лише на комп'ютер (перевірено 2026-10-12). Після push
   автор оновлює вручну: Плагіни → «⋮» → перевірити оновлення → «Оновити»;
   сам плагін нових комітів не підтягує. Локальних копій
   `<скіл>@alexgorby-skills` у Claude Code не тримати — будуть дублікати.
   Архів — запасний шлях: `pwsh ./build.ps1` → `dist/<скіл>.zip` → налаштування
   → Skills. Плагін і архів того самого скіла разом не тримати. Архів
   збирається лише з закоміченого стану.

`dist/` у git не входить.

## Вихідний стан

Перший коміт — версії, що були завантажені в Claude на 2026-10-11
(`ukrainian-tech-docs` v10 від 24.09, `ukrainian-fiction` від 07.10), узяті з
синхронізованої копії `~/.claude/skills/synced/…`. Синхронізована копія
`ukrainian-tech-docs` новіша за останній архів у `Downloads`
(`ukrainian-tech-docs_10.zip`): у `references/genres/hld.md` додано групу
«Експлуатація й нефункціональні вимоги». У `ukrainian-fiction/SKILL.md` поле
`description` взято з архіву: Claude при завантаженні переписав його в один
рядок, зміст той самий.

Ідеї для наступних правок — нота волту
`01 Projects/Скіли/Доповнення скілів — ідеї з чужих скілів — 2026-10-11.md`.
